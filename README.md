## 🚀 Featured Project: [DayPilot](https://github.com/Ravinder82/DayPilot)

A native macOS app that turns an unstructured workday into a **60-second spoken briefing** and a **friction-free morning launchpad**.

| Feature | Description |
|---------|-------------|
| 🗂 **Session Library** | Live capture + archived days, rendered Markdown editor, export (PDF/HTML/MD) |
| ⏱ **Pomodoro Timer** | 25/5/15 configurable, toolbar ring, auto-advance, sound, cycles |
| 🧠 **Memory (AI File Manager)** | Security-scoped bookmarks, recursive indexing, SHA-256 dedup, search/filter/sort |
| 🤖 **Multi-Provider AI** | Live `/models` fetch, Free/Paid badges, custom OpenAI-compatible endpoints |
| 🗣 **Voice Briefings** | On-device AVSpeechSynthesizer, auto-play, pause/resume, enhanced voices |
| 🔐 **Privacy-First** | No raw video leaves disk, sensitive app/URL blocking, Keychain keys, TCC grants survive rebuilds |

**Tech:** Swift 6, SwiftUI, ScreenCaptureKit, Vision (ANE), AVFoundation, SQLite, strict concurrency.

```bash
make install  # → /Applications/DayPilot.app (signed, Dock + Launchpad)
```
